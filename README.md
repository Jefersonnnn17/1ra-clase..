# Repaso de Programación Web II

Proyecto desarrollado en clase como parte de una sesión de repaso práctico para reforzar los fundamentos del desarrollo web frontend.

## 🛠️ Tecnologías Aplicadas

* **HTML5:** Estructura semántica del contenido web.
* **CSS3:** Estilos visuales, diseño y maquetación de la interfaz.
* **JavaScript (JS):** Implementación de interacción básica mediante ventanas emergentes (`alert`).

## 📋 Descripción

Este proyecto reúne ejercicios básicos orientados a afianzar la lógica de presentación y el comportamiento inicial de una aplicación web, conectando la estructura en HTML con estilos CSS y una interacción sencilla en JS.
